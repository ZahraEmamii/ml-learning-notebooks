# Digit Recognizer — MNIST

A handwritten digit classification project using TensorFlow/Keras and the Kaggle Digit Recognizer competition.

## Model
- Fully connected neural network (MLP)
- ReLU hidden layers
- Softmax output layer
- Sparse categorical cross-entropy loss

## Results
- Validation accuracy: approximately 97.2%
- Kaggle competition score: 0.96750

## Dataset
The dataset is available through the [Kaggle Digit Recognizer competition](https://www.kaggle.com/competitions/digit-recognizer/data).

## Notebook
See `digit-recognizer-mnist.ipynb` for data preprocessing, model training, prediction, and submission generation.
